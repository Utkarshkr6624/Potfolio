Section 01

About

I build small, complete tools and put them online. Most of my work is a front end talking to a real API and a real database. CampusPulse started as a way to stop losing track of my own coursework; SwiftPDF came from needing the same PDF operation twice and not finding a version that stayed in the browser. PixelRush and ResumeBoard are that same instinct pointed somewhere else — build the thing you actually wanted, keep it client-side, and make sure it runs. I am four years into a B.Tech at VIT-AP, and I care more about the last mile — does the thing actually run — than about picking a fashionable stack.

P-05

ResumeBoard

Paste a LinkedIn export and get a complete, editable resume in about a minute. Every word stays editable on the page, exports go to PDF, Word, Markdown and JSON with no watermark, and the ATS check names the exact line that breaks a parser — all of it in IndexedDB, with no server to send your resume to.

  • JavaScript
  • IndexedDB
  • DOCX export
  • No build step
