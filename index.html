Section 02

Work

P-01

CampusPulse

A student academic planner. Semesters, courses, assessments, grades, attendance and exam schedule in one place, with file uploads against each course and a what-if calculator for your GPA. The FastAPI backend uses SQLAlchemy over SQLite with JWT auth; the React client is TypeScript on Vite with React Router. Covered by pytest tests, and the folder carries an architecture document.

  • React
  • TypeScript
  • Vite
  • Tailwind
  • React Router
  • FastAPI
  • SQLAlchemy
  • SQLite
  • JWT
  • pytest

P-02

SwiftPDF

A PDF toolkit that runs in the browser. Merge, split, compress, crop, image-to-PDF, page numbering and saved themes. The files never leave the machine you opened them on, which is the whole point when the documents are marksheets and certificates.

  • JavaScript
  • PDF manipulation
  • Client-side processing
  • Theming

P-03

Pdf-tools

The earlier front-end-only converter, and the reason SwiftPDF exists. Merge, split, compress and image-to-PDF with no backend at all. Keeping it around because it shows how much of the PDF surface can be covered without a server.
